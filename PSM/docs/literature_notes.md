# 舆情镜像文献依据笔记

> 本笔记根据 `E:\文献\大数据` 中已放置的项目方案和论文整理，用于支撑网页系统的方法说明、作品集介绍和报告中的方法依据。

## 1. 舆情分析不应停留在静态情感分类

对应文献：

- Xu Tan 等，*An Analysis of the Emotional Evolution of Large-Scale Internet Public Opinion Events Based on the BERT-LDA Hybrid Model*
- 王世航、汤艳君，《基于情感分类和主题挖掘的网络舆情文本分析》

对项目的启发：

- 舆情事件需要同时观察情绪、主题和时间阶段，不能只输出“正面/负面比例”。
- 因此系统保留 `publish_time` 字段，并设计“舆情概览”“情感时间变化”“生命周期初步判断”。
- 第一版用轻量词典和时间聚合实现，后续可接入 BERT-LDA 或 BERT 情感模型。

落地模块：

- `src/timeline.py`
- `src/sentiment.py`
- 页面：`舆情概览`、`情感立场`

## 2. LDA、TF-IDF 与聚类共同支撑主题发现

对应文献：

- David M. Blei、Andrew Y. Ng、Michael I. Jordan, *Latent Dirichlet Allocation*
- 王世航、汤艳君，《基于情感分类和主题挖掘的网络舆情文本分析》
- 吴雨农、范文静，《基于网络文本分析的国家博物馆旅游体验研究》

对项目的启发：

- TF-IDF 适合发现事件特征词。
- LDA 适合解释潜在主题结构。
- 高频词和语义网络/文本聚类适合做可解释的开放文本分析。
- 第一版先实现词频、TF-IDF 和 K-means 观点聚类，保证运行稳定；LDA 可作为下一步增强。

落地模块：

- `src/keywords.py`
- `src/topic_modeling.py`
- 页面：`主题观点`

## 3. BERTopic 与 SBERT 是后续语义增强方向

对应文献：

- Maarten Grootendorst, *BERTopic: Neural topic modeling with a class-based TF-IDF procedure*
- Nils Reimers、Iryna Gurevych, *Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks*

对项目的启发：

- 传统词袋模型会损失上下文语义。
- SBERT 可以把句子转换成可比较的语义向量，适合相似评论识别、聚类和检索。
- BERTopic 使用 transformer embeddings、聚类和 class-based TF-IDF 形成可解释主题。
- 因为这类模型安装和运行成本较高，第一版将其设计为后续可选增强，不影响基础功能。

落地模块：

- 当前：`src/topic_modeling.py` 的 TF-IDF + K-means
- 后续：新增 SBERT/BERTopic 可选模式

## 4. 社交媒体摘要需要处理噪声和重复

对应文献：

- Freddy Chong Tat Chua、Sitaram Asur, *Automatic Summarization of Events from Social Media*

对项目的启发：

- 社交媒体事件文本通常存在噪声、重复、冗余和时间顺序特征。
- 报告不应只罗列图表，还应抽取代表性评论，形成可阅读的结构化摘要。
- 第一版用清洗、去重、聚类代表评论和模板报告实现摘要雏形。

落地模块：

- `src/preprocess.py`
- `src/topic_modeling.py`
- `src/report.py`
- 页面：`数据清洗`、`报告生成`

## 5. 立场检测必须绑定目标对象

对应文献：

- 赵小兵等，《面向社会媒体的立场检测研究综述》

对项目的启发：

- 立场检测的核心是“给定目标 + 给定文本”，判断用户对目标的支持、反对或中立。
- 情感和立场不同：负面情绪不一定等于反对目标对象，正面情绪也不一定是支持。
- 因此系统单独设置“立场分析目标对象”，并输出 `support / oppose / neutral / irrelevant`。

落地模块：

- `src/stance.py`
- 页面：`情感立场`

## 6. 谣言风险不宜直接判断真假，应先识别不确定表达

对应文献：

- 高玉君等，《社会网络谣言检测综述》

对项目的启发：

- 真实谣言检测需要数据标注、传播结构、用户特征和模型训练，不能在轻量工具中轻率断言“真假”。
- 作品第一版采取更稳妥的“信息不确定性识别”：识别“网传、据说、求证、未证实、等官方回应”等表达。
- 页面和报告都应明确：系统提示的是信息风险，不是事实裁决。

落地模块：

- `src/uncertainty.py`
- 页面：`风险研判`

## 7. 群体极化风险可转化为多指标辅助评分

对应文献：

- 卢国强，《突发事件网络舆情群体极化的风险耦合及风险评估研究》
- 李彪、吴倩，《危机语境下趣缘社群话语空间重构与维系研究》

对项目的启发：

- 群体极化风险不是单一情绪指标，而与情境事件、主体回应、用户互动、信息属性、媒体效力等因素耦合有关。
- 第一版将其轻量化为可解释指标：负面情绪、热度增长、主题集中度、反对立场、不确定信息、极端表达和互动放大。
- 风险评分只能作为文本信号的辅助研判，必须保留方法局限。

落地模块：

- `src/risk.py`
- 页面：`风险研判`

## 8. 信息资源管理视角：从工具到研究型系统

对应文献：

- 康乐乐等，《守正与创新：中国信息资源管理学科理论重构与方法创新》
- 谢超，《基于大数据分析的网络安全态势感知与响应技术》

对项目的启发：

- 项目应体现“数据采集/导入、清洗、理解、研判、响应/报告”的完整链路。
- 大数据课程作业不能只展示图表，应体现数据质量、分析流程、方法局限和输出报告。
- 作品集表达要强调跨学科：信息资源管理、文本挖掘、社会媒体研究和数据可视化。

落地模块：

- 全项目架构
- 页面：`方法说明`、`报告生成`

## 当前实现与文献的关系

第一版采取“轻量可解释优先”的策略：

- 已实现：数据导入、清洗、质量诊断、词频、TF-IDF、K-means、情感词典、规则立场、不确定信息识别、风险评分、报告生成。
- 后续增强：LDA、SBERT、BERTopic、BERT 情感模型、图表导出、作品集展示页。

这样可以保证项目先成为可运行作品，再逐步靠近文献中的高级方法。
